# 📊 Grameenphone Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Grameenphone Sales Analysis Dashboard** developed using Microsoft Power BI. The dashboard provides valuable insights into sales performance, revenue generation, profitability, customer behavior, payment methods, and data usage patterns.

The main objective of this project is to transform sales data into meaningful business insights that can support data-driven decision-making.

## 📊 Dashboard Analysis

### 1. Total Revenue by Month
Analyzes monthly revenue trends and identifies changes in sales performance throughout the year.

### 2. Revenue by Service Category
Compares revenue generated from different service categories:
- Internet Package
- Combo Package
- Postpaid Plan
- Voice Package
- Recharge
- Digital Service

### 3. Revenue by Payment Method
Evaluates revenue contribution from different payment methods:
- bKash
- Mobile Banking
- Cash
- Nagad
- Card
- Bank

### 4. Revenue by Sales Channels
Analyzes sales performance across different distribution channels, including retail stores, MyGP App, recharge shops, authorized outlets, and digital platforms.

### 5. Revenue by Customer Segment
Identifies revenue contributions from different customer segments:
- Young Professionals
- Family
- Business
- Student
- Premium

### 6. Data Usage by Age Group
Analyzes data consumption patterns across different customer age groups.
